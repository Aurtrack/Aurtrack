# ADR 0007：节点组语义与 Blender 对齐

- **状态：** 草案
- **日期：** 2026-10-27
- **决策者：** 项目维护者

## 背景

当前节点系统里有两个容易混淆的概念：

- `NodeGroup`：真正可复用的 Voice 子图数据块，带接口，可嵌套。
- `audio.group`：轨道 Audio 图里的一个乐器节点，通过 `group` 字段引用一个 Voice 组，用来给音符轨提供音色。

界面上两者都显示成“节点组”，于是用户会自然地期待 `audio.group` 像 Blender 的 Group 节点一样，在外部显示接口输入。但它实际上是一个音源，Voice 接口里的 `Pitch`、`Velocity`、`Gate` 是音符事件输入，不是 Audio 图的信号输入，所以外部只出现了 `音频` 输出。

这不是渲染漏了端口，而是领域模型没有把“组实例”和“乐器”分开。

## Blender 的节点组模型

Blender 的 Group 不是特殊效果器，而是一个可复用节点树：

- 组是独立数据块，接口由组自己声明。
- 组节点是组数据块的一个实例，外部端口由接口动态生成。
- 实例端口和组接口一一对应，输入未连接时使用实例上的默认值。
- 组可以嵌套，组输入/输出节点是子图边界。
- Tab 进入选中组，Ctrl+Tab 返回；节点编辑器没有常驻的“成组/解组/组库”按钮条。
- 组节点标题通常显示组名，类别和颜色表达“这是一个组”。
- 组接口可以有默认值、范围、面板和说明，而不只是名字和类型。

## Aurtrack 当前差距

### 1. 组只存在于 Voice 域

`NodeGroup` 的图类型固定为 `VoiceGraph`，只能在 Voice 图里作为 `voice.group` 实例。Audio 图没有通用的组实例，因此无法把一组效果器打包成可复用的 Audio 组。

### 2. 轨道里的组其实是乐器

`audio.group` 是乐器节点，不是组实例：

- 它没有动态接口输入。
- Voice 的 Pitch/Velocity/Gate 是每个音符的事件值，由片段/钢琴卷帘驱动，不能当作 Audio 连线输入。
- 它的组接口只在进入 Voice 编辑器后才有意义。

因此不能直接给它补三个假端口；要让外部端口真正可连线，必须先引入 Note/Event socket 或统一的节点树执行模型。

### 3. 组接口缺少默认值和面板

`NodeGroupSocket` 目前只有 `id`、`name`、`type`。缺：

- 未连接输入的默认值。
- Float 的范围、步进和单位。
- 接口分组/面板。
- 接口顺序和显示名编辑的完整约束。

这会导致组实例的未连接输入没有值控件，和 Blender 的组节点不一致。

### 4. 组编辑器头部是应用按钮条

之前组编辑器顶部有一排“成组 / 解组 / 组库 / 接口 / N / ×”，这是应用级操作，不是 Blender 的节点编辑器语义。Blender 把这些放在菜单、快捷键和侧栏里。

### 5. 进入组的位置不明确

整张节点卡都可以双击进入，容易误触；标题只显示“节点组”，不显示实际组名，用户不知道进入的是哪个组。轨道图和 Voice 图的进入方式也不完全一致。

## 决策

### 1. 先区分“组实例”和“乐器”

- Voice 图里的 `voice.group` 是真正的组实例，继续显示动态接口端口。
- 轨道图里的 `audio.group` 在模型升级前明确作为乐器呈现，不再假装它是通用组节点。
- UI 标题显示实际组名，并显示组接口摘要（音高/力度/门 → 音频）；这些是音符事件接口，不添加不可连线的假输入端口。
- 真正的可连线组实例仍然只在 Voice 图里，端口由组接口动态生成。

### 2. 统一导航语义

- Tab 进入选中的组，组内 Tab 退出到上一层。
- 双击只作用于组标题/组名区域，不再作用于整张卡片。
- 组编辑器不再有常驻操作按钮条；成组、解组走 Ctrl+G / Ctrl+Alt+G 和右键菜单，接口走 N 面板。
- 面包屑是唯一的层级路径显示，点击根“轨道图”返回。

### 3. 组接口补齐 Blender 式字段

后续为 `NodeGroupSocket` 增加：

- `default`：未连接输入的默认值。
- `minimum` / `maximum` / `step`：Float 的范围和步进。
- `panel`：接口在组节点上的面板归属。
- `description`：工具提示。

组节点未连接的输入显示内联值控件；连接后隐藏控件，和 Blender 的 socket 行为一致。

### 4. 长期方向：通用节点树

要让 Audio 图也拥有真正的组实例，需要把“图”从 `AudioGraph` / `VoiceGraph` 双模型提升为带域约束的通用 `NodeTree`：

- 每个域声明自己的 socket 类型集合和编译器。
- 组接口在同一域内动态生成端口。
- 组节点通过编译器内联展开，而不是靠特殊乐器节点。
- 如果未来需要 Note/Event 驱动，新增显式事件 socket，而不是复用 Float 假装事件。

这是较大的架构迁移，不在本次 UI 修复里偷跑。

## 本次落地

- 移除组编辑器头部的常驻按钮条。
- 组节点标题显示实际组名；组 ID 移到组信息行。
- 双击只从节点标题进入组，保留 Tab 和右键菜单。
- 轨道组节点保留“编辑音色”入口，不再把它当作有外部接口的通用组。
- 记录本 ADR，后续按“接口默认值 → 通用节点树”顺序推进。

## 后果

- 组编辑器更接近 Blender 的 chrome，不再有应用按钮条。
- 用户能一眼看出轨道里的 `audio.group` 是乐器而不是 Blender Group；真正的组实例仍在 Voice 图里。
- 在通用节点树完成前，Audio 组仍然不是 Blender 意义上的可复用组实例，这是明确的已知限制。
